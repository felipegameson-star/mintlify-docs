## O que é um pipeline

Um **pipeline** é um quadro Kanban que representa as etapas do seu processo comercial. Cada contato vira um **card** que você arrasta de uma etapa para outra conforme avança na negociação.

Exemplos de pipelines: `Vendas B2B`, `Captação de Leads`, `Pós-venda`, `Onboarding`.

## Criar um pipeline

<Steps>
  <Step title="Acesse Pipelines">
    No menu lateral, clique em **Pipelines**.
  </Step>
  <Step title="Clique em Novo Pipeline">
    Botão no topo direito da tela.
  </Step>
  <Step title="Dê um nome">
    Digite o nome do pipeline (ex: `Vendas 2025`).
  </Step>
  <Step title="Adicione as etapas">
    Clique em **+ Adicionar etapa** para criar cada coluna do Kanban. Exemplos: `Novo Lead`, `Qualificação`, `Proposta`, `Fechado`.
  </Step>
  <Step title="Salve">
    Clique em **Salvar**. O pipeline aparece no menu de pipelines.
  </Step>
</Steps>

## Limite de pipelines por plano

| Plano | Pipelines | Etapas por pipeline |
|-------|-----------|---------------------|
| Essencial | 2 | 8 |
| Crescimento | 5 | 15 |
| Sob consulta | Ilimitado | Ilimitado |

## Gerenciar etapas

Para adicionar, renomear ou reordenar etapas:

1. Com o pipeline aberto, clique nos **três pontos** no nome do pipeline
2. Selecione **Configurar pipeline**
3. Arraste as etapas para reordenar, ou clique para renomear/excluir

## Duplicar pipeline

Duplicar cria uma cópia com as mesmas etapas, mas sem os cards existentes. Útil para criar variações de um processo.

<Steps>
  <Step title="Abra o pipeline que deseja duplicar">
    Clique no nome do pipeline no seletor superior.
  </Step>
  <Step title="Clique no ícone de duplicar">
    Passe o mouse sobre o nome do pipeline e clique no ícone de copiar (dois quadrados).
  </Step>
  <Step title="Renomeie se necessário">
    O novo pipeline é criado com o nome `[Nome original] (cópia)`. Renomeie conforme necessário.
  </Step>
</Steps>

<Note>
  Duplicar pipeline **não** copia os campos personalizados. Você precisará recriar os campos no pipeline duplicado.
</Note>

## Renomear e excluir pipeline

- **Renomear**: clique no ícone de lápis ao lado do nome do pipeline
- **Excluir**: clique no ícone de lixeira (ação irreversível — apaga todos os cards do pipeline)
