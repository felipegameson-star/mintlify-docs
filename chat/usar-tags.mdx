## O que são tags

Tags são etiquetas coloridas que você aplica a um contato. Elas aparecem como **chips** no painel lateral da conversa.

Servem para:

- **Organizar** os contatos por tema (ex: "interessado", "cliente", "sem perfil")
- **Segmentar** sua base na hora de filtrar conversas ou montar uma lista
- **Disparar automação** quando uma tag é adicionada ou removida

## Adicionar uma tag a uma conversa

<Steps>
  <Step title="Abra a conversa">
    Clique no contato na lista de conversas do chat.
  </Step>
  <Step title="Vá ao painel do contato">
    No painel lateral direito, encontre a seção **Tags**.
  </Step>
  <Step title="Adicione a tag">
    Clique para adicionar uma tag. Escolha uma tag existente ou crie uma nova.
  </Step>
</Steps>

## Remover uma tag

Para tirar uma tag de um contato, clique no **x** do chip da tag no painel lateral. A tag é removida na hora.

## Usar tags para disparar automações

Quando você adiciona ou remove uma tag, isso pode servir de **gatilho** para uma automação. Por exemplo: ao marcar um contato com a tag "interessado", uma automação envia uma mensagem de follow-up.
